# Dragon Book

I'm currently working on this project while reading **"Compilers: Principles, Techniques, and Tools"**, also known as the **Dragon Book**.

The idea is simple: while I read the book, I try to implement what I'm learning.

## Objective

My goal is to create an entire compiler using **Go**.

I chose Go mostly because I want to learn the language. I know there are other languages that could make some parts easier, like Python or Haskell, but learning Go is part of the process.

## Background

Before this project, I tried to build an interpreter using **Rust**, following the book **"Crafting Interpreters"**.

It was rough.

Most of the time, I was breaking my head trying to understand how the borrow checker works and how to actually write Rust code properly.

## Progress

As I go through the book, I'll try to document everything here.
